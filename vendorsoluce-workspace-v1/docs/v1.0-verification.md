## Issues found

### Blocking defect 1 — React infinite update loop
- **Symptom**: App threw “Maximum update depth exceeded” due to unstable `useSyncExternalStore` snapshots when selectors returned new arrays/objects.
- **Fix**: Cache selector results per selector function when underlying store state reference is unchanged.
- **Status**: Resolved

### Blocking defect 2 — Test expectations not met
- **Symptom**:
  - Risks were not auto-generated on High criticality vendor intake.
  - Actions did not support “In Progress / Completed” statuses.
- **Fix**:
  - Auto-generate 3 baseline risks on creation of High criticality vendors.
  - Add action statuses `In Progress` and `Completed` and persist them.
- **Status**: Resolved
