Configuration-Gated Delivery

Downloads are released after a short environment setup with your team, so you get the right edition from the start.

Download access is gated through a short configuration workflow. We validate deployment model, security boundaries, and integration scope before delivering a build package and activation details.

Build and package options

Local base build

Air-gapped or locally managed edition for teams that require offline execution and local data persistence.

  • • Fully local execution path
  • • No mandatory backend dependency
  • • Assessment and report exports

Backend-integrated build

Connects VendorSoluce™ to platform and portal workflows for multi-user collaboration and operational continuity.

  • • Team workflows and role-based access
  • • Evidence collection through the portal
  • • Ongoing synchronization and governance

White-label edition

Enterprise branding and client-facing customization for teams operating a branded assurance program.

  • • Brand and UI customization scope
  • • Domain and communication alignment
  • • Enterprise delivery governance

Radar-to-Portal premium integration

Premium integration where Vendor Radar defines assessment requirements and the portal operationalizes collection and evidence handling.

  • • Requirements generated from risk posture
  • • Portal-based vendor response workflows
  • • Premium price driver for integrated assurance

Delivery and monetization model

Path What is included Commercial model
Configuration-gated download Environment validation, build selection, delivery package Delivered after technical scoping
