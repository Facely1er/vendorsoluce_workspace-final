Spreadsheet import help

Easiest way: , fill one row per vendor, then choose Import CSV. Your first row can be plain-English headers—we recognize common names automatically.

What to put in each column (you can leave advanced fields blank):

  • Name — vendor or service name
  • Category — how important they are (for example strategic vs. commodity)
  • Data types — kinds of data they touch; use a semicolon between several values
  • Sector, location, contact, notes — optional context for your team

Risk scores and similar columns are optional—we calculate them when you run a scan if you leave them empty.

Exact column titles (for power users)

If you build the file yourself, these header names work in any order: Name, Category, Data Types (;-separated list), Sector, Location, Contact, Notes, Service Type, Population Impacted, Inherent Risk, Residual Risk, Risk Level. Service type, population, and risk fields stay optional.

Same list in the VendorSoluce app? Use Import portfolio and Export portfolio in this toolbar to move the full vendor list as one portable file—no need to copy column names by hand. Or use Continue in app in the welcome banner or toolbar to open the platform with import guidance.
