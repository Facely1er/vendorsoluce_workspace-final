# ERMITS NIST baseline (synced)

This folder is a **copy** of the [@ermits/nist-compliance-template](https://github.com/...) source. It is not a package dependency; it is synced so this app can customize it without affecting other products.

- **To refresh** from the template: from `ermits-nist-template` run `npm run sync`.
- **Import** from this folder, e.g. `import { FEATURE_IDS, THEME_BASELINE_LIGHT } from '@/lib/ermits-template'` or `from '../lib/ermits-template'`.
